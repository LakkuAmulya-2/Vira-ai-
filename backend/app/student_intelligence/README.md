# Phase 6 Student Intelligence

Student intelligence is persistent, explicit and user-owned.

Profile dimensions:
- academic records
- interests and strengths
- skills
- career goals
- budget
- country preferences
- explicit constraints
- bounded memory

Agents receive a personalization context and apply stored constraints before executing grounded retrieval. Memory is namespaced, confidence-scored and upserted by key; it is not an unrestricted chat transcript.
