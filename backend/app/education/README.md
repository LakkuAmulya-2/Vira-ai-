# Global Education Canonical Data Domain

Phase 1 canonical entities are Countries, Institutions, Courses, Programs, Scholarships and Entrance Exams.

No seed records are included. Production data must enter through verified source ingestion and review workflows. API writes require administrator authorization; student-facing reads require authentication.

Entity records begin as PENDING_VERIFICATION and should only be surfaced for critical recommendations after verified provenance exists in education_facts / knowledge_claims.
