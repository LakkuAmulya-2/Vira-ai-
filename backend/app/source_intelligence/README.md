# Phase 3 Source-Specific Intelligence

Regional adapters are code paths, not hardcoded datasets.

Supported adapter keys:
- india_official
- us_official
- uk_official
- eu_official
- gulf_official

Every real source must be registered as a SourceProfile by an administrator. The profile controls region, country, category, allowed URL paths, crawl interval and adapter.

No university, scholarship, exam or deadline data is embedded in source code.
